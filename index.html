  • User Account Managment, Audit, & Privilege Configuration
    In this project, I set up a secure Linux environment focused on user management, privilege control, and auditing. I created multiple user accounts (admin1, partner1, partner2), configured group permissions and limited sudo access using visudo, enforced password expiration policies with chage, and enabled system auditing using auditctl and ausearch. I documented everything step-by-step, tested real command-line scenarios like locking/unlocking users, and set up audit rules to log activity on critical system files like /etc/passwd. This lab helped me understand how access control, logging, and least privilege all work together to harden a system. It also sharpened my terminal skills and gave me a better grasp on how sysadmins and security analysts enforce real security policies.
